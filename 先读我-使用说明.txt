网页影片一键采集助手 v0.1.2 — Windows 11 x64 免安装测试包

本包复用原包的 Windows x64 启动器、Python 3.13.17 和 Pillow 12.3.0。
普通用户无需安装 Python 或编译。本次未重新编译 EXE，尚未完成 Windows 真机验证。

本次修复：
1. 新建影片目录不再追加 [b78f945859] 一类摘要；真正重名才使用 (2)、(3)。
2. 优先使用 Chrome 当前网络和可用会话获取原图，再传给本地程序校验并保存原始字节。
3. 支持附件服务器返回通用二进制类型，不把登录页、错误页或缩略图当作原图保存。
4. 修补同步回内附源码，版本号和交付校验值统一更新。

使用与更新：
1. 等待当前采集完成，将完整包解压或更新到固定本地目录，不要从压缩软件中直接运行。
2. 保持扩展与本地程序使用同一版本，保留 runtime 文件夹。
3. 双击“首次使用-注册.bat”，通过自检并选择影片保存根目录。
4. Chrome 打开 chrome://extensions，加载 extension 文件夹；已有扩展点击“重新加载”。
5. 设置中确认本地程序已连接，打开帖子并检查两张原图地址和磁力。
6. 点击采集，首次允许 Chrome 访问当前识别出的图片站点。
7. BitComet 中仍需手动确认保存目录；发送磁力不代表添加成功或下载完成。

已有带摘要的旧目录不会自动改名，以保持原 BitComet 路径可用。
复用旧目录时可能仍显示旧名；新建目录采用新规则。
如需整理旧目录，应先停止相关下载，保留 metadata.json，改名后更新 BitComet 的保存路径。
metadata.json 仍用于去重与完整性校验；TXT 可以在插件中关闭保存。

浏览器获取失败会记录原因并尝试本地下载。实际网站、代理、登录态和 Windows 联动仍需真机确认。
检查缺失文件不会调用 BitComet；只有主动勾选“再次发送磁力”才重发已有记录的链接。
移动程序目录后重新注册。移除时等待任务结束，运行“取消注册.bat”并在 Chrome 移除扩展。
设置、日志和历史保存在 %LOCALAPPDATA%\ChromeMediaCollector，已有影片不会删除。

完整说明和实际测试范围见内附 source-code.zip 中 README.md 及 docs/TEST_RESULTS.md。
